# Library Management System 

## Overview

This project is a SQL-based database system designed to manage
and analyse Library Management System .

## Project Statement

The public library maintains thousands of books across multiple categories. Members borrow and return books every day. But the library currently records transactions manually. The management wants a database system that stores book information, member details, borrowing records, and a librarian information to improve efficiency and generate useful reports. My job as a SQL data analyst is to design the database, organize the data, and generate reports that answer the library business questions.

## Project Objectives

Design a relational database and generate reports that help library management understand:
1. which books are borrowed the most?
2. which members borrow the most books?
3. which book categories are most popular?
4. Monthly borrowing trends ?
5. Librarian performance ?
6. Available versus issued books?
7. Overdue books?
8. Most active members?
9. Book return statistics?
